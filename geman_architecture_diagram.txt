KEY DESIGN ELEMENTS
═════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

✓ Hierarchical Encoding:      Separate encoders for nodes and vehicles
✓ Multi-relational Graph:      Truck and drone edge relations processed separately
✓ Bilevel Decoding:            Independent heads for node and vehicle decisions (no coupling)
✓ Cross-Attention Pattern:     Each decoder sees mean embedding of the other modality
✓ Adaptive Pooling:            Learned weights for context aggregation
✓ Feasibility Masking:         Action constraints enforced via -∞ masking
✓ Attention-based Selection:   Dot-product attention for soft selection of next location/vehicle
✓ Tanh Clipping:               Logits clipped to [-clip, +clip] for numerical stability
✓ Flexible Graph Encoder:      Supports GraphEncoder, EGAEncoder, and MEGA variants

TRAINING LOOP INTEGRATION
═════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

Forward Pass:
  1. obs dict → unpacking (to torch tensors)
  2. Encoders: (Z_node, g_node), (Z_veh, g_veh), (Z_graph, g_graph)
  3. Decoders: node_logits, veh_logits
  4. Combine: flat_logits (N+1)*2K logits
  5. Value: scalar V(s)

Policy Loss (PPO):
  dist = Categorical(logits=flat_logits)
  log_probs = dist.log_prob(actions)
  policy_loss = -log_probs * advantages  (+ entropy bonus)

Value Loss (MSE):
  value_loss = (V(s) - returns)^2

Total Loss:
  loss = policy_loss + λ_v * value_loss + λ_ent * entropy
