================================================================================
                        PPO NORMALIZATION STACK
================================================================================

PPO has THREE LAYERS of normalization/clipping for gradient stability:

LAYER 1: ADVANTAGE NORMALIZATION ✅ (NEW - Line 211)
────────────────────────────────────────────────────────────────────────────

Formula:
  advantages_normalized = (advantages - mean) / (std + 1e-8)

Effect:
  • Rescale advantages to mean 0, std 1
  • Ensure consistent loss magnitudes across batches
  • Prevent training instability from large advantage swings

Example:
  Before:  advantages ∈ [-0.01, 0.01]  → loss = 0.0001
           advantages ∈ [-100, 100]    → loss = 100
           (Huge variance!)

  After:   advantages ≈ [-1, 1]        → loss ≈ 0.5
           advantages ≈ [-1, 1]        → loss ≈ 0.5
           (Consistent)

Used in:
  surr1 = ratio * advantages_normalized
  surr2 = clamp(ratio) * advantages_normalized


LAYER 2: PPO CLIPPING ✅ (Existing - Line 233)
────────────────────────────────────────────────────────────────────────────

Formula:
  ratio = exp(new_log_probs - old_log_probs)
  clipped_ratio = clamp(ratio, 1 - clip_eps, 1 + clip_eps)
  
  surr1 = ratio * advantages
  surr2 = clipped_ratio * advantages
  loss = min(surr1, surr2)

Effect:
  • Prevent policy from changing too fast in one update
  • Default clip_eps: 0.2 (policy ratio ∈ [0.8, 1.2])
  • Protects against overoptimization

Example:
  If new policy is 2x better (ratio=2.0):
    surr1 = 2.0 * advantage = 2.0a
    surr2 = clamp(2.0) * advantage = 1.2a
    → Use surr2 (prevents policy from changing too much)


LAYER 3: GRADIENT NORM CLIPPING ✅ (Existing - Lines 252-254)
────────────────────────────────────────────────────────────────────────────

Formula:
  ||∇|| = sqrt(sum(g_i^2 for all parameters))
  
  if ||∇|| > max_grad_norm:
    ∇_clipped = ∇ * (max_grad_norm / ||∇||)

Effect:
  • Prevent exploding gradients
  • Default max_grad_norm: 0.5 (conservative)
  • Preserve gradient direction, limit magnitude

Example:
  Before:  ||∇|| = 100 (huge update)
  After:   ||∇|| = 0.5 (safe)
  
  Direction preserved, magnitude capped

Config:
  agents:
    tune_agent:
      max_grad_norm: 0.5


================================================================================
                         HOW THEY WORK TOGETHER
================================================================================

Batch receives advantages with large variance:
  advantages ∈ [-500, 500]

           ↓ Layer 1: Advantage Normalization
           
  advantages_norm ≈ [-1.5, 1.5]
  (Consistent scale across batches)

           ↓ Layer 2: PPO Clipping
           
  Prevents policy from changing more than 20% per update
  (clip_eps = 0.2 means ratio ∈ [0.8, 1.2])

           ↓ Layer 3: Gradient Norm Clipping
           
  If gradients still large, clip them to max_grad_norm=0.5
  (Final safety net)

           ↓ Optimizer Step
           
  Safe, stable parameter update


================================================================================
                          WHEN EACH MATTERS
================================================================================

Advantage Normalization:
  ✓ Variable advantage scales across batches
  ✓ Long-horizon problems (large returns)
  ✓ Mixed easy/hard episodes in same batch
  ✓ Different task difficulties

PPO Clipping:
  ✓ Prevents overfitting to single batch
  ✓ Enables multiple gradient steps (ppo_epochs)
  ✓ Keeps policy close to old policy
  ✓ Standard PPO mechanism

Gradient Norm Clipping:
  ✓ Protects against gradient explosion
  ✓ High learning rates
  ✓ Unstable loss landscapes
  ✓ Non-stationary environments

  learning_rate: 0.0005

  clip_eps: 0.1             ← Small policy changes

AGGRESSIVE (Fast Training):
  learning_rate: 0.005
  max_grad_norm: 1.0        ← Loose clipping
  clip_eps: 0.3             ← Larger changes
  
  Effect: Faster but riskier


================================================================================
                       WHAT EACH LAYER PREVENTS
================================================================================

Layer 1 (Advantage Norm):
  Prevents: Training instability from large advantage variance
  Symptom (without): Loss ∈ [0.0001, 100] (huge range)
  Symptom (with):    Loss ≈ 0.5 (consistent)

Layer 2 (PPO Clipping):
  Prevents: Overoptimization on single batch
  Symptom (without): Policy ratio goes to 10.0 (huge change)
  Symptom (with):    Policy ratio ∈ [0.8, 1.2] (controlled)

Layer 3 (Grad Norm Clip):
  Prevents: Exploding gradients
  Symptom (without): ||∇|| = 1000 (parameters jump far)
  Symptom (with):    ||∇|| = 0.5 (small, safe step)


================================================================================
                            DEBUGGING TIPS
================================================================================

If training is unstable:
  1. Check: Print std(advantages_normalized) - should be ≈ 1.0
  2. If too high: advantages_normalized not working properly
  3. Reduce learning_rate by 2-10x
  4. Tighten max_grad_norm (0.5 → 0.3)

If learning is too slow:
  1. Check: Is advantage_normalized saturating at ±1?
  2. Increase learning_rate
  3. Increase entropy_coef for exploration
  4. Loosen max_grad_norm (0.5 → 1.0)

If high variance between runs:
  1. Advantage norm + grad clipping should help
  2. Try increasing ppo_epochs (3 → 5)
  3. Fix random seed for debugging
