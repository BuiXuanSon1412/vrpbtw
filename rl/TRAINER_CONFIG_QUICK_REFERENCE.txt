                              MetaTrainer (MAML)
================================================================================

File: configs/trainer/meta.yaml

AGENTS NEEDED:
  ✓ meta_agent    (aggregates task losses)
  ✓ sub_agent     (task-specific inner-loop)
  ✓ tune_agent    (fine-tuning from meta-learned weights)
  ✓ eval_agent    (evaluation)

COLLECTOR:
  name: gae                  (Generalized Advantage Estimation)
  rollout_length: 256        (trajectory length)

PHASES:

  1. Meta-Learning (optional - set enabled: true/false)
     ├─ Curriculum:
     │  ├─ entropy_threshold: 0.5      (when to expand tasks)
     │  └─ check_interval: 1           (every N batches)
     ├─ Control:
     │  ├─ epochs: 200                 (meta-training epochs)
     │  ├─ batches_per_epoch: 50       (FOMAML iterations)
     │  ├─ eval_interval: 1            (evaluate every N epochs)
     │  └─ checkpoint_interval: 10     (save every N epochs)
     └─ Early Stopping:
        ├─ patience: 20                (stop after N plateaus)
        └─ min_delta: 0.0001           (improvement threshold)

  2. Fine-Tuning (optional - set enabled: true/false)
     ├─ Control:
     │  ├─ epochs: 50                  (per-task epochs)
     │  ├─ batches_per_epoch: 100      (batches per epoch)
     │  ├─ ppo_epochs: 3               (gradient steps per batch)
     │  ├─ eval_interval: 1            (evaluate every N epochs)
     │  └─ checkpoint_interval: 10
     └─ Early Stopping:
        ├─ patience: 10
        └─ min_delta: 0.0001

TYPICAL CONFIGURATIONS:

  Quick Test:
    meta_learning:  epochs=10, batches=5, eval_interval=2
    fine_tuning:    epochs=5, batches=10, ppo_epochs=1
    → ~5 minutes

  Realistic:
    meta_learning:  epochs=100, batches=30, eval_interval=5
    fine_tuning:    epochs=50, batches=100, ppo_epochs=3
    → ~2-4 hours

  PPO Only (meta_learning disabled):
    fine_tuning:    epochs=100, batches=100, ppo_epochs=3
    → ~1-2 hours

LEARNING RATES:
    meta_agent:     0.0001 to 0.001   (lower for aggregation)
    sub_agent:      0.001  to 0.005   (standard task-specific)
    tune_agent:     0.001  to 0.01    (can be higher)

File: configs/trainer/pomo.yaml

     │  ├─ batches_per_epoch: 10       (batches per epoch)

     │  ├─ eval_interval: 1            (evaluate every N epochs)
     │  └─ checkpoint_interval: 10
     └─ Early Stopping:               [NEW: with recent fixes]
        ├─ patience: 20
        └─ min_delta: 0.0001

TYPICAL CONFIGURATIONS:

  Quick Test:
    epochs=10, batches=5, instances=1, eval_interval=1
    → ~5 minutes per task

  Realistic:
    epochs=50, batches=20, instances=1-4, eval_interval=2
    → ~30-60 minutes per task

  High Quality:
    epochs=100, batches=50, instances=2, eval_interval=1

LEARNING RATES:
    train_agent:    0.001  to 0.005   (standard RL)

ENTROPY:
    entropy_coef:   0.05   to 0.2     (higher for exploration)

================================================================================
                            KEY DIFFERENCES
================================================================================

MetaTrainer Features:
  ✓ Multi-task learning (curriculum)
  ✓ FOMAML inner-loop adaptation
  ✓ Generalizable policy across tasks
  ✗ Slower (MAML overhead)
  ✗ More complex configuration

POMOTrainer Features:
  ✓ Simple, direct training
  ✓ Per-instance baselines
  ✓ Fast training per task
  ✓ Multiple optima exploration
  ✗ Task-specific only (no transfer)
  ✗ Sequential tasks (can't parallelize)

================================================================================
                        WHEN TO USE WHICH
================================================================================

Use MetaTrainer when:
  → Want one policy that generalizes to new task distributions
  → Have diverse task sizes/distributions
  → Want quick adaptation with few examples
  → Can afford longer training time

Use POMOTrainer when:
  → Want best performance on specific tasks
  → Each task is independent
  → Want faster, simpler training
  → Have limited compute budget

================================================================================
                          COMMON WORKFLOWS
================================================================================

WORKFLOW 1: Compare algorithms on single task
  1. Run MetaTrainer with meta_learning=false (pure PPO)
  2. Run POMOTrainer
  3. Compare final policies

WORKFLOW 2: Develop generalizable policy
  1. Enable MetaTrainer with curriculum
  2. Let it expand through task distribution
  3. Optionally fine-tune on specific task

WORKFLOW 3: Production deployment
  1. Train MetaTrainer (get generalizable weights)
  2. Copy weights to POMOTrainer
  3. Fine-tune on deployment tasks with early stopping

WORKFLOW 4: Ablation studies
  1. Toggle meta_learning enabled: true/false
  2. Adjust ppo_epochs (1, 3, 5)
  3. Adjust curriculum entropy_threshold
  4. Compare convergence speed and final performance
