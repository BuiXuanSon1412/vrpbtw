🧠 GEMAN Architecture

Graph-Enhanced Multi-relational Attention Network for VRPBTW

Overview

GEMAN is an actor-critic neural network designed for the Vehicle Routing Problem with Time Windows and Drones (VRPBTW). It makes bilevel decisions: (1) which location to visit and (2) which vehicle to use.

The Big Picture

Observation Input ↓ ├─ Node Encoder ──→ (Z_node, g_node) ├─ Vehicle Encoder ──→ (Z_veh, g_veh) └─ Graph Encoder ──→ (Z_graph, g_graph) ↓ Node Decoder ──→ node_logits Vehicle Decoder ──→ vehicle_logits ↓ Joint Logits ──→ flat_logits (policy) Value Head ──→ value (critic)

Main Components

1. Node Encoder

Encodes location information with heterogeneous attention

Input: node_features (B, N+1, 5)
Output: Z_node (B, N+1, D), g_node (B, D)
Architecture: Linear → 3×Attention → Pooling
Parameters: ~200K

2. Vehicle Encoder

Encodes vehicle information (truck and drone variants)

Input: vehicle_features (B, 2K, 5)
Output: Z_veh (B, 2K, D), g_veh (B, D)
Architecture: Linear → 3×Attention → Pooling
Parameters: ~200K

3. Graph Encoder (Multi-Relational GNN)

Captures spatial-temporal routing structure via truck and drone relations

Input: Node coords + truck/drone edges
Output: Z_graph (B, N+1, D), g_graph (B, D)
Architecture: 3×Multi-Relational Layers
Parameters: ~150K

4. Node Decoder

Selects which location to visit using attention

Inputs: g_node, mean(Z_veh), g_graph, Z_node
Output: node_logits (B, N+1)
Mechanism: Context projection → Dot-product attention
Parameters: ~65K

5. Vehicle Decoder

Selects which vehicle to use using attention

Inputs: g_veh, mean(Z_node), g_graph, Z_veh
Output: veh_logits (B, 2K)
Mechanism: Context projection → Dot-product attention
Parameters: ~65K

6. Value Head

Estimates state value V(s) for advantage computation

Input: cat[g_node, g_veh, g_graph] (B, 3D)
Output: value (B,)
Architecture: Multi-layer MLP
Parameters: ~66K

Key Features

  • Hierarchical Encoding: Separate encoders for nodes and vehicles
  • Bilevel Decoding: Independent decoders prevent coupling
  • Multi-relational GNN: Separate truck/drone graph relations
  • Cross-Attention Pattern: Each decoder sees other modality's mean
  • Adaptive Pooling: Learned weights for context aggregation
  • Action Masking: Feasibility constraints via -∞ masking
  • Numerical Stability: Tanh clipping and NaN handling

Computational Complexity

Component Time Complexity Space Complexity
Node Encoder (N² attention) O(B×N²×D) O(B×N×D)
Vehicle Encoder (K² attention) O(B×K²×D) O(B×K×D)
Graph Encoder (E edges) O(B×E×D) O(B×E×D)
Decoders & Value Head O(B×(N+K)×D) O(B×D²)
TOTAL O(B×(N²+E)×D) O(B×(N+K+E)×D)

Note: For typical VRPBTW instances (N~100, K~5), total inference time ~10-50ms per batch on modern GPUs.
